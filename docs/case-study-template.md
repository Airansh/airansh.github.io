# Case study authoring template

Status: authoring template. This file makes no claims about a completed system.

- Title, organization, dates, team context, and exact personal contribution
- Problem and intended users
- Functional requirements
- Non-functional requirements, supported metrics, and measurement method
- Constraints and assumptions
- High-level architecture and source evidence
- Component responsibilities and data flow
- Database design, ownership, and migration approach
- API contracts, validation, and error behavior
- Security, authentication, authorization, and sensitive-data boundaries
- Scalability, reliability, timeouts, retries, and recovery
- Performance evidence and limitations
- Technical choices, alternatives, and documented tradeoffs
- Testing strategy, actual execution results, and untested boundaries
- Deployment architecture and operational responsibilities
- Results and impact with exact scope and provenance
- Personal reflections or lessons supplied by the author
- Approved screenshots, public code excerpts, diagrams, and supporting links
- Open documentation items

Do not manufacture decisions or lessons. Mark future exercises as planned. Separate the existence of a test suite from proof that it passed in a particular environment.
